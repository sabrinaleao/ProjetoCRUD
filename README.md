# CRUD de Produtos — Spring Boot + JPA + MySQL

Atividade prática UMC. Tema: **Produto** (nome, preço, estoque).

## Como rodar
1. Abra o XAMPP e inicie **MySQL** e **Apache**.
2. Rode a aplicação (`CrudProdutosApplication`) ou `mvn spring-boot:run`.
   O banco `produtos_db` é criado automaticamente.
3. Acesse http://localhost:8080/produtos
4. Confira os dados em http://localhost/phpmyadmin

Se o seu MySQL tiver senha, defina a variável de ambiente `DB_PASSWORD` (a senha não fica no código).
